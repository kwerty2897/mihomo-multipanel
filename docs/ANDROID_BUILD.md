# Android CI build

The Android project is generated by Tauri CLI during GitHub Actions; generated Gradle files are not committed initially.

- Workflow: `.github/workflows/android-apk.yml`
- Trigger: push to main affecting app files, or manually from Actions.
- Minimum SDK: 24 (Android 7.0).
- Artifact: APK uploaded to the workflow run for 14 days.

The first CI run is intended to validate the scaffold and toolchain. If it fails, inspect the Actions log and adjust generated Android project or SDK versions. Android 7 compatibility remains subject to device/WebView testing.
